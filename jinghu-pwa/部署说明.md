# 京沪公交慢行手册 · iPhone 安装说明

这个压缩包就是一个完整的 App（PWA，渐进式网页应用）。上传到 GitHub Pages 后，在 iPhone Safari 里"添加到主屏幕"，就能像一个原生 App 一样全屏使用，断网也能打开全程方案。

## 包里是什么

- `index.html` —— 手册本体（18天行程 + 地图 + 贴士 + 预算 + 清单）
- `manifest.webmanifest` + `sw.js` —— 让网页变成可安装、可离线 App 的两个配置文件
- `vendor/` —— 地图库 Leaflet 的本地副本（不依赖外部网络加载）
- `icons/` —— App 图标

## 部署到 GitHub Pages（一次性，约10分钟）

### 第1步：注册 GitHub 账号
打开 github.com 用邮箱免费注册。已有账号直接跳过。

### 第2步：新建仓库
登录后点右上角 **+ → New repository**：
- Repository name 填 `jinghu-handbook`（或任意英文名）
- 可见性选 **Public**（免费版 Pages 要求公开仓库）
- 其余默认，点 Create repository

### 第3步：上传文件
解压本压缩包，进入新仓库页面：
- 点 **Add file → Upload files**
- 把解压出来的**全部内容**（index.html、manifest.webmanifest、sw.js、vendor 文件夹、icons 文件夹）拖进上传区
- 等进度条走完，点 **Commit changes**

### 第4步：开启 Pages
- 进仓库的 **Settings → 左侧 Pages**
- Source 选 **Deploy from a branch**
- Branch 选 **main**、文件夹选 **/ (root)**，点 Save
- 等1-2分钟，页面顶部会出现你的网址：`https://你的用户名.github.io/jinghu-handbook/`

### 第5步：装到 iPhone
- 用 iPhone 的 **Safari**（必须是 Safari）打开上面的网址
- 点底部 **分享按钮（方框带向上箭头）→ 添加到主屏幕**
- 桌面出现"京沪手册"图标，点开就是全屏 App，没有地址栏

## 出发前做一次离线验证
1. 连 Wi-Fi 打开 App，把18天卡片点一遍、地图放大缩小看看沿线——看过的底图会自动存进手机
2. 开飞行模式再打开，确认能正常显示 → 离线能力就绪（新看地图区域仍需联网，旅途中手机有信号即可）

## 之后想改行程怎么办
在 GitHub 仓库里点开 index.html → 点铅笔图标编辑 → 改完 Commit。手机上重新打开一次页面即生效（离线缓存会自动更新）。

## 兜底
万一哪天 GitHub 访问不了：这个压缩包本身就是完整应用，解压后在电脑上双击 index.html 也能看（地图底图需联网，文字内容不受影响）。
